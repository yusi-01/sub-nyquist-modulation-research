# GATE-3C Oracle 与 Blind 可行性实验报告

日期：2026-11-03。研究阶段：只读物理可行性与固定算法开发检查；**没有 CNN 训练、没有新数据 H5、没有读取 Final Test**。方法数学推导见《GATE3C_多陪集盲支持估计与观测增强_数学设计.md》。

## 1. 协议与门禁顺序

冻结 v2 数据：Train 16900、Validation 3380、Development 3380 个独立双信号源，每源 11 档 SNR。先用正式 Train 20 源核验无噪声测量恒等式（`complex128` 最大误差 `1.76×10⁻¹⁴`）与 Oracle；再完整运行 Validation Oracle，确认无负有效 SNR 收益和无明显信号破坏后，才运行预固定的两轮 SOMP。Development 仅在算法及 q 区间冻结后运行一次。`source_uid` 每档恰 3380；统计以源为簇。固定 Coset、槽映射、噪声种子和 IQ/8；没有用真实 slot 回填盲预测。

## 2. Oracle：物理可行性 PASS

Validation 3380 个 clean 源在两真实槽子空间的平均相对能量失真 **0.0212%**、最大 **0.0991%**；Development 为 **0.0211%/0.1209%**。高能主频区 `q=235…789` 的正式 Train 20 源近似误差约 `0.0106%`；带外相对误差约 `24%`，但其能量小。两槽近似不是逐 q 严格精确。

Validation 全 37180 视图的 Oracle 平均投影噪声能量比 **0.25001**，符合秩二投影的理论 `2/8`；平均有效 SNR 增益 **6.003 dB**。−10/0/+10 dB 分别为 **6.021/6.014/5.951 dB**，全部视图增益均为正。Development 对应 **6.003/6.022/6.014/5.946 dB**（首项为全档均值）。这同时计入有限窗导致的信号失真，不能等同于调制识别准确率提升。

## 3. Blind：支持与信号质量 PASS（物理层）

Validation 和 Development 各 3380 源×11 档。双槽支持按无序集合评估。Validation 在 −10 dB 完全正确 **3327/3380=98.43%**，其余十档全部正确；Development 在 −10 dB **3329/3380=98.49%**，其余十档全部正确。第一轮总能命中真实槽；错误均来自第二槽未补全，且全部发生在 −10 dB。Validation 169 种有序调制组合各含 13–27 源，Development 各含 9–31 源；详见组合支持 CSV，不能对单个小组宣称稳定性。

Validation 盲投影全档平均有效 SNR 增益 **6.002 dB**，低 SNR（−10 至 0）源级均值 **6.0159 dB**、95% 成组区间 **[6.0146,6.0171] dB**；Development 低 SNR **6.0160 [6.0147,6.0172] dB**。没有负增益视图。Validation −10 dB 支持错误的 53 视图增益均值 **5.219 dB**、最低 **5.022 dB**，仍比 Raw MCS 的该有效 SNR 定义高，但低于支持正确组约 **6.021 dB**。错误支持对 clean 信号的相对能量失真均值约 **24.27%**（Development 51 视图约 **24.17%**），说明单看总误差下降会掩盖调制特征损失风险。预固定的明显错误支持对照在 −10 dB 平均仍可得到约 3.86 dB 表观收益，到 +10 dB 为约 −12.14 dB，进一步说明必须同时看 clean 保真和噪声。

## 4. 间距、相关性与错误传播

Validation 的 −10 dB 错误中 **52/53** 来自间距 12 个槽，另 1 个来自间距 8；Development 对应 51 个错误。按预固定分组，Validation −10 dB 的间距 1–2、3–5、6–11、12–23 源数分别为 **561/735/1120/964**，支持正确率 **100%/100%/99.91%/94.61%**；`|rho|<0.2`、`0.2–0.4`、`≥0.4` 源数 **1444/1255/681**，正确率 **100%/100%/92.22%**。这些关联同时受精确槽间距及字典结构约束，**不能将 |rho| 单独认定为错误的因果原因**。完整 11 档分层、每组源数、均值 `eta`/`rho` 见 CSV。

## 5. 逆变换与泄漏边界

正式 Train 20 源×3 档检查：盲投影后各支路 1024 点正交 IFFT 得到 8×1024 复数序列，可按原 Coset 顺序交织为 `[1024,16]` `float32`，全为有限值；无时序重排、逐样本归一化或额外缩放。检验中 IQ/8 的八路平均功率在原始 Noisy 观测约 `0.088–0.089`，投影后约 `0.044–0.046`；该下降同时包括噪声与少量信号，不能独立作为去噪成功证据。正式 Blind 函数只接收 MCS 频域观测；Oracle、错误支持与 clean Full 仅用于离线诊断。未将真实 slot、调制标签、SNR 或 Full 独有观测传入 Blind 处理。

冻结 Raw MCS checkpoint 未用于投影 IQ 分类：直接输入会构成分布外测试，且不能替代公平重训。因此 **最终调制准确率收益仍是 UNKNOWN**。

## 6. 统计、留存与裁决

完整结果文件：`GATE3C_逐SNR支持估计结果.csv`、`GATE3C_投影前后信号质量.csv`、`GATE3C_不同子带间距与相关性分析.csv`、`GATE3C_源级统计与置信区间.csv`、`GATE3C_调制组合支持数量.csv`；源级与逐视图可复核摘要保存在 `formal_validation_blind/` 和 `formal_development_blind/`，原 H5 与 checkpoint 均未覆盖。脚本只读 H5，未产生派生大 H5。服务器当时四卡各约 48.66 GiB 空闲、RAM 可用约 113 GiB、磁盘可用约 232 GiB；算法用 CPU 串行逐源处理，内存增长未见异常。

**A 数学可行性：PASS。** 频域恒等式和 24 槽映射核对，双槽 Gram 可稳定 QR 投影；实际有限 RRC 信号全频失真均值约 0.021%。

**B Oracle 可行性：PASS。** 实际噪声能量约降至四分之一，有效 SNR 平均提高约 6 dB，无明显总体信号破坏。

**C Blind 可行性：PASS（当前冻结双信号 AWGN 合同）。** −10 dB 双槽完全正确率超过 98%，其余档全对；不使用真实槽。

**D 误差传播：有边界。** 支持错误时 clean 失真约 24%，虽低 SNR 总有效 SNR 仍净增，是否损害调制特征尚未由分类器验证。

**E 分类研究价值：有条件 YES。** 物理门禁允许下一轮**另行批准**一个 Blind Projection + 随机初始化原生 SHELL16 的严格配对训练；当前绝不能宣称分类收益。

**F 创新潜力：** SOMP、QR、子空间投影均是成熟算法。论文可能的新贡献只可能来自低 SNR 双信号 MCS 调制识别任务中的误差与特征保护分析、严格公平分类对照和适用边界；这些分类证据目前 UNKNOWN，不能声称新恢复理论或首次提出经典算法。

**G 最终停止裁决：PASS（物理/Blind 可行性）。** 只建议未来单一候选的公平训练；本轮不训练、不设计第二算法。Final Test 保持封存。

### 一页结论

这项方法针对 MCS 在两占用频带下的 8 路混合观测，利用冻结采样矩阵和跨 FFT 索引的共同支持，把观测投影到估计的双槽测量子空间。在本数据合同中，它在多数低 SNR 视图中保住了干净信号，抑制了约四分之三的观测白噪声。它**无需真实 slot 即可运行**，但 −10 dB 少量支持误判会删除约四分之一的 clean 能量。故当前已具备进入**另行批准的单模型 SHELL16 分类验证**的物理依据，尚无证据证明调制识别准确率会提高。
