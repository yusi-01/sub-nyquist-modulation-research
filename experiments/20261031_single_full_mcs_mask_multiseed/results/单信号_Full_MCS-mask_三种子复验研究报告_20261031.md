# 单信号 Full80 / MCS-mask80 三种子复验研究报告

> 2026-10-31；仅使用 Development Test。训练种子 271060、271061、271062；三次评价使用相同的2,600个源和相同的11档 view/noise 身份。未读取 Final Test，未启动双信号、方案B或采样结构新模型训练。

## 1. 结论

1. **低 SNR Full 优势得到三种子支持。**−10、−6、−2 dB 的 Full−mask 准确率差在三个种子中均为正：分别为 **18.00–24.31、16.38–19.58、8.96–10.04 个百分点**，每个种子的逐源配对95% CI均高于0。
2. **+4 至 +10 dB 的 MCS-mask 反超方向也在三种子中一致**，但幅度并不稳定。前两个种子反超约2–3个百分点，271062 在 +10 dB 反超 **11.15 个百分点**。因此可以说交叉方向复现，不能说交叉幅度稳定。
3. **Full80 的高 SNR 平台稳定，MCS-mask80 的平台高度与构成不稳定。**Full 在 +4 至 +10 dB 均约0.80–0.82；mask 在271060/271061约0.82–0.84，但271062继续由0.880升至0.917。三者的主要错误常集中在 PSK8/16、QAM64/256，不过错误方向随种子显著变化。
4. 三种子支持的是固定协议下的**经验分类差异**；同架构/参数量并未消除零填充导致的有效 fan-in、权重优化和 BN 统计差异，不能称作物理信息损失的最终证明。
5. **可以进入预注册的最小采样位置归因准备**，但先校准 `A_C` 与 FFT 索引并预计算候选 Coset 矩阵相关性；不应依据本次 Development 准确率反向选择 Coset，也不在本轮直接启动新训练。

## 2. 数据和训练门禁

- 同一 train/Validation H5、同一11档 Full component SNR（−10至+10 dB、步长2 dB）、同一信号与噪声；mask 臂只将非固定 Coset 通道置零。三种子 Development 的 `source_uid/view_uid/noise_seed/SNR/label/slot` 完全一致，每档2,600个 view、每类200个。
- 每个模型200 epoch，Res1dNet311、80输入通道、3,885,965参数、batch 1024、Adam lr 0.01、weight decay 1e−4、warm-up 5、余弦退火、label smoothing 0.1、AMP/TF32、无逐样本 RMS。各臂按相同训练 seed 从随机初始化；没有加载历史 checkpoint。seed 271060 有初始化状态直接核对记录，新增两对通过相同代码路径和 seed 保证协议一致，但未保存初始权重逐张量对比文件。
- 所有 checkpoint 均按 Validation accuracy 选择，Development 不用于选点。最佳 epoch：Full **166/170/156**，mask **162/153/118**（按种子顺序）。最佳 Validation accuracy：Full **0.7430/0.7336/0.7390**，mask **0.6775/0.6619/0.6862**。
- 两次新评价均通过11档输出门禁；四份训练配置中的 checkpoint SHA-256 均与评价时重算哈希一致。原串行脚本在发现并行训练进程后按防重复规则停止；四个模型训练本身均完成。失败预检日志已单独保存，不能算作训练 seed。

## 4. 高 SNR 平台与类别构成

|种子|Full +4/+10 ModAcc|mask +4/+10 ModAcc|Full +10 F1|mask +10 F1|
|---:|---:|---:|---:|---:|
|271060|0.8012 / 0.8119|0.8215 / 0.8369|0.7950|0.8327|
|271061|0.7992 / 0.8181|0.8188 / 0.8377|0.8139|0.8291|
|271062|0.8019 / 0.8050|0.8804 / 0.9165|0.7915|0.9008|

Full +10 ModAcc 三种子均值 **0.8117±0.0065**；mask 为 **0.8637±0.0457**。mask 的大波动同时体现在 Macro-F1（+10 为0.8327/0.8291/0.9008），并非仅靠单一类别预测偏置提高总准确率，但仍有类别间代价交换。

在 +10 dB，PSK8↔PSK16 与 QAM64↔QAM256 两对合计占 Full 总错误的 **67.3%/73.8%/73.2%**，占 mask 总错误的 **96.7%/86.0%/88.0%**。因此“错误集中在相邻阶数”相对稳定；**具体方向不稳定**：

- mask 271060：PSK8→16 为62、逆向147；271061 为150、逆向46；271062 为0、逆向0。271062 的两类 recall/precision 均为1.0，说明这批 Development 源在该训练解下并非必然不可分。
- mask 271060：QAM64→256 为101、逆向100；271061 为58、逆向109；271062 为176、逆向15。271062 的 QAM64 recall 仅0.095，QAM256 recall 0.910，表现出新的单向偏置。
- Full 的 PSK16→PSK8 在 +10 dB 为144/101/164，三个种子均比逆向更多；QAM64/256 的方向仍变动。Full 平台的错误**类别对**较稳定，但错误方向和类别 recall 不能称稳定。
- 按历史“预测该类少于26次/档2,600 view”判据，新两臂仅 seed 271062 mask 在 −10 dB 的 APSK64(4次)、QAM64(13次) 与 −8 dB 的 APSK64(12次) 共3项，无零预测项。此判据不能替代逐类 recall 和混淆方向分析。

训练曲线在 `训练曲线.csv`。最后10个 epoch 的 Validation accuracy 均值：Full 0.7389/0.7290/0.7342，mask 0.6725/0.6500/0.6706；最佳 epoch 不在末轮，按 Validation 选点有必要。高 SNR 的 Development 平台并非训练曲线的同义词。

## 5. 假设 A–E 判定

|假设|判定|证据边界|
|---|---|---|
|A −10/−6/−2 Full 优势|**支持，方向稳定**|三个种子均正，单种子逐源 CI 均不跨0；幅度仍有种子差异|
|B +4至+10 mask 反超|**方向支持，幅度不稳定**|三个种子各档均负、单种子 CI 均小于0；271062 增益远大于前两个|
|C 两臂高 SNR 平台|**Full 支持；mask 仅部分支持**|Full 高档变化小；mask 271062 从+4至+10继续提高3.61 pp|
|D 类别混淆方向|**不稳定**|mask 的 PSK8/16、QAM64/256 在种子间翻转甚至消失；不能写成固定单向物理混淆|
|E 采样密度/固定 Coset 是否值得追究|**值得做最小预注册归因**|低 SNR 差距稳健，但当前仍混有输入表示、有效 fan-in 和优化条件|

## 6. 下一阶段最小实验

1. **只读校准**：固定 Fs=2 GHz、L=40、M=8，复核 `A_C` 的 Coset 行顺序、列对应的40个频率 bin、FFT 正负号/归一化及占用子带索引；用基向量和单音数值检验形成一份校准表。此阶段不训练。
2. **数据无关的 Coset 候选登记**：保持 M=8、信号、噪声、标签、源划分、SNR 和模型协议不变，原 Coset 为基线；按预先计算的测量矩阵 Gram、列相关系数、最大相干度及目标子带条件数，预注册最多两组替代采样位置。候选在查看其任何 Development/Test 准确率前冻结，不按准确率反向选点。
3. **最小位置归因**：若校准通过，对原位置与两组替代位置使用相同三个训练种子、相同初始化与 Validation 选点，先比较低 SNR 配对差及类别错误是否随矩阵相关性有预期变化。由于位置变动也会改变输入稀疏模式，需保留同架构 mask 控制和优化诊断。此项为下一阶段计划，本轮未启动。
4. **采样数量单独后置**：只在位置实验显示可解释趋势后再设计 M 的最小梯度，不与 Coset 位置同时改变。保持 Fs=2 GHz、L=40 及全部源/噪声/标签，明确不同 M 下的训练初始化与计算预算匹配。

当前论文措辞可写“在三训练种子的同架构控制下，Full 在低 SNR 具有稳定经验分类优势，高 SNR 的 mask 反超方向复现但幅度和类别边界高度依赖优化结果”；不可写“固定 Coset 的物理信息损失已被证明”。
