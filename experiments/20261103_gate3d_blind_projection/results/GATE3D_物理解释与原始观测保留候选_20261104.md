# GATE-3D 阶段研究总结与原始观测保留候选

日期：2026-11-04（北京时间）。性质：**只读理论审查与下一阶段预注册设计**。本轮没有训练、生成数据、改变物理参数或读取 Final Test。依据为[冻结 GATE-3D 单种子报告](GATE3D_BlindProjection_SHELL16_单种子分类验证报告.md)、[GATE-3C 物理可行性报告](../../20261103_gate3c_blind_support/results/GATE3C_Oracle与Blind可行性实验报告.md)、冻结预测及训练记录。

## 1. 结论先行

GATE-3D 的物理投影**确实降低了八路观测的总白噪声能量**，并使当前 SHELL16 在极低 SNR 获益；它同时在中高 SNR 及 PSK8、QAM16 等类别上造成分类退化。该结果是**单训练 seed、冻结 v2 双信号 AWGN 数据、当前网络与协议下的 Development 现象**，不能上升为跨 seed 稳定结论。GATE-3D 保持 **PARTIAL**，不重新选 checkpoint、不修改已完成结果。

下一项唯一值得**另行批准**的开发候选是：**保留原始观测的固定测量结构双视图判别**。它只用一个共享的原生 Res1dNet31(16,26)，分别读取 Raw MCS 与冻结 Blind 投影视图，以由输入自身估计的能量比例作固定、无可训练参数的 logit 融合。它针对的是“投影去除噪声的同时可能压低判别特征、而 Blind-only 网络无法回看 Raw”的问题；不是新支持恢复算法，不宣称创造信息。此方案具有物理合理性，**可作为一个单 seed Development 训练候选，当前尚未获准执行**。

## 2. 正确支持时的秩二投影：严格理论关系

对每个正交 FFT 索引 `q`，在消去已知、模长为一的 Coset 频率相位 `D[q]` 后，写作

\[
\widetilde Y[q]=A_S X[q]+N[q],\qquad N[q]\sim\mathcal{CN}(0,\sigma^2 I_8),\quad |S|=2.
\]

这里的 `A_S` 是冻结字典中两个占用槽的列，满列秩；实际八路频谱中的投影算子为 `D[q] P_S D[q]^H`，其中

\[
P_S=A_S(A_S^H A_S)^{-1}A_S^H=U_SU_S^H,
\quad P_S^H=P_S,\quad P_S^2=P_S,\quad \operatorname{rank}(P_S)=\operatorname{tr}(P_S)=2.
\]

冻结代码使用 QR 构造 `U_S`，避免显式求逆；因此下列结论适用于代码中的**正确支持、白噪声、理想双槽线性模型**，不是对任意实际 RRC 波形的无条件等式。

### 2.1 总噪声能量与约 6 dB

正交 FFT 保能，令每个 `q` 上原噪声协方差为 `σ²I₈`。原八路噪声期望能量为 `E||N[q]||²=8σ²`；投影后为

\[
E\|P_SN[q]\|_2^2=\operatorname{tr}(\sigma^2P_S)=2\sigma^2.
\]

跨 `Q=1024` 个索引分别为 `8Qσ²` 和 `2Qσ²`，**期望总能量比 `2/8=0.25`，降低 75%**。若信号严格在该子空间内且不变，用“信号总能量 / 八路噪声总能量”定义的比值增加 `10log₁₀(4)=6.0206 dB`。冻结 GATE-3C 的 Validation Oracle 实测平均噪声能量比 **0.25001**、平均有效 SNR 增益 **6.003 dB**；有限窗误差使实测有效增益并非恰好 6.0206 dB。这里是**期望能量的比**，单个有限样本的能量比会波动。

### 2.2 信号子空间内部的噪声并未变小

投影噪声协方差为 `Cov(P_SN)=σ²P_S`。在 `U_S` 的两个正交坐标内，

\[
\operatorname{Cov}(U_S^H P_SN)=\sigma^2I_2,
\qquad U_S^H P_SN=U_S^H N.
\]

也就是说投影清掉的是六维正交补噪声，**两个信号坐标中的白噪声没有被额外压低**。若用最小二乘估计双槽系数，

\[
\widehat X=(A_S^H A_S)^{-1}A_S^H\widetilde Y,
\qquad \operatorname{Cov}(\widehat X-X)=\sigma^2(A_S^H A_S)^{-1}.
\]

先投影再估计得到完全相同的 `\widehat X`，其噪声放大仍由双槽 Gram 矩阵决定。因此总能量 SNR 的约 6 dB 增益，既不是两个已占用槽系数估计 SNR 的无条件 6 dB 增益，也不是调制分类的 6 dB 横向平移。

### 2.3 充分统计量等式

由 `P_SA_S=A_S` 与 `P_S=P_S^H`，有 `A_S^HP_S=A_S^H`，从而

\[
A_S^HP_S\widetilde Y=A_S^H\widetilde Y.
\]

在**已知正确支持、各调制假设只改变子空间内信号、理想复白高斯噪声协方差相同**时，观测的正交补只含与调制假设无关的噪声；`A_S^H\widetilde Y` 对子空间内信号是充分统计量。理想最优判别器不因丢掉这部分正交补噪声而获得新信息。有限容量、有限数据、特定卷积归纳偏置的 SHELL 可以因输入更集中而改善，也可能因特征损失或分布变化而恶化；这属于实际模型性能，不是信息论收益。**当支持未知时，正交补也可能包含区分支持假设的信息**，上述已知支持结论不能直接套在 Blind 支持估计上。

### 2.4 实际合同的限制

冻结 GATE-3C 在真实 v2 clean 数据上测得双槽近似的全频平均相对能量失真约 **0.0211%**，高能主频区近似更好，带外相对误差较大但能量较小。RRC、有限观测窗、频谱泄漏使 clean 信号不严格等于 `A_SX`；实际 `(I-P_S)\widetilde Y` 可同时含噪声和小量信号。总能量损失很小不保证对 QPSK、PSK8、QAM16 等**特定判别特征**也小。Blind 支持错误又使 `P_{\widehat S}` 不再含真实信号子空间；Development 的 51 个错误视图 clean 能量失真约 **24.17%**。若噪声不是理想白噪声，上述 `σ²P_S` 和 `2/8` 能量结论也不再自动成立。本报告不对新的噪声域作外推。

## 3. GATE-3D 的实测失败边界

所有以下差值来自冻结相同 `source_uid/view_uid/noise_seed` 的 3380 个 Development 源，每源 11 档视图，以源为 Bootstrap 簇；比较对象是**各自从随机初始化训练的两套 SHELL16 权重**，因此不能仅由差值精确拆出物理投影、训练优化与输入分布的单独因果效应。

| 现象 | 冻结证据 | 可说的结论 |
|---|---|---|
| 极低 SNR 收益 | −10 dB PairExact `7.04%→14.14%`；−8 dB `15.09%→19.62%`；−6 dB `22.04%→24.79%` | 在这三个档位 Blind-only 分类器优于 Raw；低 SNR −10～0 dB 汇总 `25.330%→27.406%`，源级 95% 区间对应净增 **+1.223～+2.929 pp**。 |
| 中高 SNR 退化 | 自 0 dB 起逐档 PairExact 转负；+2～+10 dB 汇总净差 **−4.965 pp**，源级区间 **−6.426～−3.497 pp**；全 11 档 **−1.124 pp** | 收益局限于极低 SNR，当前 Blind-only 处理链不满足全档稳健性。 |
| 支持错误局部损失 | 仅 −10 dB 有 51/3380 错误支持；该组 Blind PairExact 1.96%，Raw 5.88%；Blind 相对 Raw 在该组 0 个独有正确、2 个独有错误 | 支持错误有局部风险，但分组受槽间距和类别分布混杂，不能把差值当纯因果损失。+2～+10 dB 支持全对，**高 SNR 退化不能归因于 SOMP 错误**。 |
| 类别决策偏向 | 低 SNR PSK8 Recall `33.0%→16.8%`，PSK16 `39.6%→57.9%`；高 SNR PSK8 `41.6%→16.1%`；低 SNR `PSK8→PSK16` 错误 `1213→1873` | 表示和分类边界明显偏向 PSK16，不能将 PSK16 Recall 的增长单独当进步。 |
| 原混淆未解 | 低 SNR `QPSK→PSK16/PSK8` 合计 `1636→1700`；`QAM16→APSK64` `797→1074`；`QAM64→APSK64` `562→844` | 关键额外混淆没有得到共同改善；不能宣布 GATE-3D 解决论文核心问题。 |

特别注意：`PSK8→PSK16` 和 `PSK16→PSK8` 的方向变化说明**类别预测频数也必须与 Recall 同看**。输入分布、重新随机初始化的优化轨迹、共享 CNN 对弱判别特征的响应以及非严格双槽物理近似，各自贡献尚为 **UNKNOWN**。GATE-3D 只证明当前整条处理链的分类结果，不单独证明“正交补一定含重要调制信息”或“网络一定无法利用投影数据”。

## 4. 唯一下一方法候选：原始观测保留的固定双视图判别

### 4.1 研究问题与必要性

Raw MCS16 保留全部八路观测，却在极低 SNR 受噪声干扰；Blind-only 能抑制正交补噪声，但把 Raw 从 CNN 输入中删除，并在中高 SNR 与 PSK8 等类上退化。故唯一候选直接检验：**一个不增加 SHELL16 参数、始终保留 Raw、同时允许冻结投影视图参与判别的受限融合，能否保住极低 SNR 的局部收益并避免 Blind-only 的高 SNR 代价？**

这不是从 Development 选择多个融合公式。以下公式在任何候选训练或 Development 评价前固定；若物理/数值门禁不通过即停止，不尝试第二公式。

### 4.2 数学定义与信息边界

设 `y[q]∈C⁸` 为原始八路 IQ/8 的 1024 点正交 FFT，`\widehat S(y)` 为 GATE-3C 已冻结的两轮 SOMP；`D[q]` 为已知 Coset 相位。定义

\[
v[q]=D[q]^Hy[q],\qquad u[q]=D[q]P_{\widehat S(y)}v[q].
\]

对八路 `y`、`u` 分别作正交 IFFT，并按同一固定 Coset/IQ 顺序重排，得到 `x_raw,x_proj∈R^{16×1024}`。`x_raw` 与原 SHELL-MCS16 输入**逐点相同**，没有第二次除以 8；`x_proj` 与 GATE-3D Blind 输入逐点相同。两者都只由同一八路 MCS 观测和公共已知参数确定。

仅用于**固定融合系数**的可观测量为

\[
\widehat\sigma^2(y)=\frac{\sum_q\|(I-P_{\widehat S})v[q]\|^2}{(8-2)Q},
\quad \widehat E_S(y)=\max\!\left(0,\frac{\sum_q\|P_{\widehat S}v[q]\|^2}{Q}-2\widehat\sigma^2\right),
\]
\[
\widehat\gamma(y)=\frac{\widehat E_S(y)}{2\widehat\sigma^2(y)+\epsilon},
\qquad \alpha(y)=\frac{1}{2+\widehat\gamma(y)}\in(0,1/2].
\]

`ε` 只取实现 dtype 的固定机器精度以避免零除，不按数据或 Development 选择。**这是预固定的启发式可靠性权重，不是 Bayes 最优权重或真实 SNR。** 在理想正确支持与白噪声下，`\widehat\sigma²` 的残差估计无偏；低观测信号强度时 `α` 接近 1/2，高强度时趋于 0。有限窗信号外泄或错误支持会污染该估计，必须单独验收。

以**同一组** `θ` 的原生 `f_θ=Res1dNet31(16,26)` 做两次前向，定义唯一候选的 26 维 logits：

\[
\ell_\theta(y)=[1-\alpha(y)]f_\theta(x_raw)+\alpha(y)f_\theta(x_proj).
\]

只在融合 logits 上使用原 SHELL 的 26 维平滑标签 BCEWithLogits；不增加一致性损失、辅助头、注意力、可学习门控或真实支持/SNR。两个前向**共享全部权重**，可训练参数量与 Raw MCS16 完全相同，输入通道、分类头与主干均为原生 16 通道结构，但计算量与中间激活显存会增加。`α≤1/2` 保证 Raw logit 在每个视图中权重至少 1/2，且高估计信号强度时投影视图权重趋零。训练与推理使用完全同一公式。

从**观测层面**，候选处理依赖的二元组 `(x_raw,x_proj)` 明确包含 `x_raw`，因此没有像 Blind-only 那样在进入判别前强制丢弃原始八路信息；`x_proj` 是 Raw 的确定性函数，绝不创造新的观测信息。**从最终 logits 层面**，加权平均仍可能丢失或抵消判别信息，`α` 的上下界不保证性能单调，也不保证可从输出重建 Raw。所能检验的是当前有限 SHELL 在固定表征与融合规则下的归纳偏置。

### 4.3 为什么可能有效及可能失败

- 低 SNR：投影视图减少六维正交补噪声，可给有限 CNN 一个更集中的信号子空间视图；Raw 视图仍可提供投影弱化的调制细节。
- 中高 SNR：当观测内估计的信号相对残差噪声提高，`α` 连续缩小，Raw 判别占主导；这**可能**减轻 Blind-only 在高 SNR 的类别偏向，但共享权重训练仍可改变 Raw 特征，绝非性能保证。
- 失败边界：错误支持会把信号能量计入残差，可能令 `\widehat\sigma²` 偏高、`α` 不合时宜地增加；有限窗/RRC 外泄可造成同类偏差；若 PSK8 等关键调制特征主要存在于投影弱化成分，哪怕 Raw 权重不低也可能受共享网络优化和 logit 平均拖累。若两个视图学习目标冲突，单一共享网络未必能同时拟合。两次前向比 Raw 基线耗时更长。

上述物理依据足以形成**一个可证伪的开发实验**，但不足以把这套经典 SOMP、QR 和固定加权融合称为原创反混叠方法或论文核心贡献。若其结果为正，仍需另议必要消融与跨 seed 证据；本轮不扩展方案。

**状态：设计完成，等待用户明确批准。** 仅在代码与正式 H5 的一次 P0 门禁确认 `x_raw`、`x_proj`、`α` 数值及资源后，允许单项训练：

| 项目 | 冻结要求 |
|---|---|

| 支持/投影 | 复用 GATE-3C 冻结 SOMP、Coset、`q` 区间、QR 投影和正交 IFFT；预测支持可只缓存轻量索引；真实 slot 不进入模型或权重计算 |
| 模型 | 一个随机初始化、共享权重的原生 Res1dNet31(16,26)，seed 271060；不加载 Raw/Blind/Full checkpoint，不增加可训练参数 |
| 输入与融合 | 上节唯一固定公式；Raw IQ 与原 MCS16 逐点一致、投影 IQ 与 GATE-3D 逐点一致；`α` 只依赖当前 MCS 观测，不读取真 SNR、标签或其他 split |
| 训练 | 200 epoch 上限、batch512 个源视图、原 0.026 标签平滑 BCEWithLogits、Adam `lr=0.001`/`weight_decay=0.0001`、5 epoch warmup + cosine；两个视图融合后计算**一次**原 BCE；仅 Validation 逐路 ModAcc 选 checkpoint |
| 资源 | 正式 batch512 的双前向、反向和峰值显存门禁；每次服务器操作前核对四卡显存、可用 RAM、磁盘；只在 `zh_3220241128` 自有目录建独立输出，不覆盖 GATE-1/3C/3D；不提前落盘 16 通道派生大数据集 |
| 对照 | 冻结 Raw MCS16 为主基线，冻结 Blind-only 为失败边界参照，Full80 为完整观测参考；不重训任何旧模型 |

预先固定的评价：低 SNR（−10～0 dB）和全 11 档的 PairExact、逐路 ModAcc、Macro-F1；11 档曲线；13 类 Recall/Precision/F1 与预测频数；特别列出 PSK8、PSK16、QPSK、QAM16、QAM64、QAM256，`QPSK→PSK8/PSK16` 合计及分别、`PSK8↔PSK16`、`QAM16/QAM64→APSK64`；+2～+10 dB 是否退化。与三冻结模型严格核对 `source_uid/view_uid/noise_seed`，以独立源为簇计算 `D_plus`、`D_minus` 和成组区间。支持错误的 51 个 −10 dB 视图单列，但总体指标永远包含它们。Development 不参与 checkpoint 或融合参数选择。

**预注册否定条件：** 若低 SNR PairExact 或 Macro-F1 未优于 Raw，候选假设不成立；若低 SNR 有益但高 SNR PairExact 再出现明显负差、全 11 档 PairExact 未至少追平 Raw，或 PSK8/QAM16 等重点类仍有明显 Recall 损失，不能晋升为稳健方法。`QPSK→PSK8/PSK16` 合并错误若未下降，不得宣称解决原核心混淆；只转移 PSK8/PSK16 预测频数不算改善。若 `α` 在高 SNR 并未下降、出现非有限值、支持缓存身份错位或原始 Raw 输入不再逐点一致，**P0 FAIL，停止训练**。一次候选失败后停止，不按 Development 调整权重、阈值或另试编码。

本候选的**必要性**来自 GATE-3D 的明确矛盾：Raw 低 SNR 缺少投影降噪视图，Blind-only 在中高 SNR 丢失可回看的 Raw 视图。它的**价值仍待证伪**；两次共享前向带来的计算开销也必须与真实收益同报。当前只批准了设计，未批准实施。

## 6. 对论文可用与不可用的表述

**可作为当前阶段的论文开发证据：** 固定 Coset、固定 v2 AWGN、严格同源同噪声下，秩二投影的总白噪声能量约为原来的四分之一；冻结 SHELL16 单 seed 的 Blind-only 分类在 −10～−6 dB 有收益，但低 SNR 汇总增益有限，并伴随高 SNR 与 PSK8 退化；Blind 支持错误仅集中于 −10 dB，不能解释高 SNR 损失。这些结论有[完整逐视图配对、逐类混淆和源级区间](GATE3D_BlindProjection_SHELL16_单种子分类验证报告.md)支撑。

**只能称为现象或待检验假设：** 投影究竟删除了哪类调制判别细节；CNN 的输入分布/优化限制各占多少；固定双视图能否同时保留极低 SNR 收益和高 SNR 稳定性；是否跨 seed、跨域成立。不得把总能量 SNR +6 dB 写成分类判别 +6 dB，或把简单拼接、固定融合、SOMP、QR 称为新物理恢复理论。

**本轮决定：** 一个候选具备物理合理性，值得在另行批准后做一次严格大数据单 seed Development 验证；此前保持 GATE-3D **PARTIAL**。完成本设计即停止，不自动训练或生成新的研究分支。
