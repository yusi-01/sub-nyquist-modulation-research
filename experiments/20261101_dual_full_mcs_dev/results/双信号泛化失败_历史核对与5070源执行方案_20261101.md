# 双信号独立源泛化失败：历史核对、新噪声诊断与 5070 源执行方案

日期：2026-11-01。状态：**只读诊断完成；5070 源训练方案待下一阶段执行**。本轮未训练、未读 Final Test，未更改物理合同或旧 checkpoint。

## 一、五个决策问题

1. **研究问题：**当前双信号模型的独立源识别失败，主要是否由训练源不足及记忆固定噪声视图造成？
2. **上一轮证据：**1690 源模型训练 PairExact 近 100%，Validation 仅 Full 3.95%、MCS 2.42%；足以确认泛化失败，但不足以判断原因。单信号 Coset 位置结果无法解释双信号的源泛化。
3. **下一训练唯一主要变量：**MCS-mask80 的独立训练源从 1690 增至 5070；保留原 1690 源及原 Validation/Development，其他模型、优化与物理设置固定。
4. **支持/否定：**若独立源 Validation 和 Development 的逐路 ModAcc、PairExact、Macro-F1 同向明显改善，训练与独立源差距缩小，支持“源数量不足是重要因素”；若不改善，反对继续直接堆源，转查输入表示、标签排序或模型归纳偏置。单 seed 仅给探索性因果线索。
5. **决策：**当前先冻结执行方案；不启动训练。训练完成后按预注册门槛决定继续、停止或转向。

## 三、同训练源新噪声只读检验

使用当前冻结最佳 checkpoint，在 **−2 dB** 对全部 1690 个训练源读取原 `clean_full_iq`，按原记录的 Full 域目标噪声功率重新生成独立复 AWGN；源、两路标签、观察时间、SNR、Coset 和模型不变。对照原 H5 同源同档含噪视图。脚本 `dual_fresh_noise_probe.py`；结果 `fresh_noise_probe_minus2_20261101.json`。

|模型|原训练视图 PairExact / 逐路 ModAcc|同源新噪声 PairExact / 逐路 ModAcc|
|---|---:|---:|
|Full80|100.00% / 100.00%|50.30% / 68.52%|
|MCS-mask80|99.94% / 99.97%|30.18% / 51.80%|

结果支持**固定含噪视图记忆**：只换噪声，准确率大幅下降。同时，新噪声但同一干净源的成绩仍显著高于此前独立 Validation 的整体 3.95%/2.42% PairExact，提示**源特征记忆或源分布泛化困难**。后者跨 SNR 汇总与单档比较不能量化精确差额，需补同档独立 Validation 后才能量化。新噪声实验只有 −2 dB，一个训练 seed，不能外推全部 SNR。它未发现标签或数据 P0 错误，也没有排除网络归纳偏置。

当前 v2 数据抽查已核实 train/Validation/Development 源 UID、Clean Full 哈希、两槽与两标签重生成一致；−2 dB 三 split 的实测噪声功率约 1.585，输入无逐样本归一化。频率排序后的 169 种组合不精确均衡，当前 train 每组合 5–15 源，Development 有 7 种缺失。这些是小样本限制，不能将生成顺序均衡误写成模型输出顺序均衡。

## 四、5070 独立训练源的最小执行合同（本轮不启动）

**关键实现门禁：不能直接把现有生成器的 `train` 计数由 1690 改为 5070 后重生成。**`split_schedule` 按总数生成并打乱调制/槽位安排，旧序号可能对应新的标签或槽位；即便 UID 字符串相同，干净波形也可能不同，破坏“保留原 1690 源”的单因素对照。

1. 原 `train/dataset.h5` 的 1690 源和 18590 个噪声视图逐字节复用，记录源 UID、`clean_full_hash`、11 档 `noise_seed` 的摘要。Validation/Development H5 保持只读与哈希不变。
2. 在新目录只生成 **3380 个新增训练源**，使生成顺序 169 种有序调制组合各新增 20 源；新 UID 使用独立且明确的追加命名空间，不能与现有三 split 或历史 UID/clean hash 冲突。每源 11 档 Full component SNR −10:2:+10，同一复 AWGN 后抽历史 Coset，Full/MCS 同源共噪声。追加阶段只使用训练 split 元信息，不读取 Development 预测。
3. 用虚拟拼接 Dataset 或经校验的新 H5 将旧 1690 + 新 3380 组成 5070 源。新旧波形、UID、标签、槽位、噪声 seed 不变；用源级 QA 检查交集为零、每源 11 档、Full/MCS 逐点配对、生成顺序组合各 30 源，并报告频率排序后的真实分布。
4. 仅训练 **一个**新 MCS-mask80，seed 271070，完全复用 `DualV6(80,13)`、batch256、Adam lr1e−3、weight decay1e−4、label smoothing0.1、200 epoch、固定16活动通道输入以及 Validation PairExact/Macro-F1 选点。随机初始化，不加载旧 checkpoint。新输出目录必须不存在；不得覆盖旧实验。
5. 训练前复核 generator SHA、训练代码 SHA、模型参数量、数据 manifest、训练命令、四卡占用和主机 RAM/磁盘。现有 train H5 为 7.4 GiB；若保存完整 5070 源 H5，按比例约 22 GiB，另留临时生成与 checkpoint 空间。2026-11-01 只读观察为 GPU 各约 48 GiB 空闲、主机 available 113 GiB、磁盘空闲 272 GiB；**这些不是未来启动时的资源保证**。
