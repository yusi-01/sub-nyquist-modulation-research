# GATE-3E 固定双视图共享 SHELL16：单种子 Development 审计

- `history.csv` 共 200 行，epoch 1–200 连续；Validation 逐路 ModAcc 最大值在第 **106** 轮，为 **67.979%**，与 `best_validation.json` 一致。该轮训练/Validation 损失为 **0.084471/0.110510**，Validation PairExact **47.281%**。第 200 轮训练/Validation 损失 **0.050075/0.140433**；选模没有使用 Development。

## 3. 类别与原始混淆

低 SNR QPSK Recall：Raw **36.282%**、Blind-only **38.718%**、融合 **78.782%**、Full **约完整观测参考**。QPSK→PSK16/PSK8 合并错误由 Raw 的 **970+666=1636/3120** 降至融合的 **187+247=434/3120**；这项预注册关注的混淆在当前冻结预测中确实大幅减轻。共享 Projection 单分支仅 **146+196=342/3120**，优于固定融合，故不能把这一改善单独归因于融合公式。

同时存在代价：低 SNR PSK8 Recall Raw **33.045%**、融合 **31.378%**（−1.667 pp）；高 SNR Raw **41.615%**、融合 **35.615%**（**−6.000 pp**）。高 SNR QAM256 Recall **16.4%→12.4%**（−4.0 pp）；全 11 档 QAM256 **13.339%→11.329%**，仍是严重共同瓶颈。高 SNR APSK16 也下降约 1.731 pp。全 11 档 QAM16 Recall **41.032%→52.797%**，QAM64 **37.010%→44.738%**；PSK16 **45.717%→56.014%**。PSK8 与 PSK16 的相反变化提示决策偏向尚未消除。完整预测频数见逐类 CSV，例如全 11 档融合预测 PSK16 **6806** 次、PSK8 **4240** 次，真实各 **5720** 次。

## 4. 同网分支、α、支持错误

共享网络内，低 SNR Projection 单分支 PairExact **36.706%**，固定融合 **36.326%**；高 SNR **61.284%** 对 **60.598%**；全 11 档 **47.878%** 对 **47.359%**。融合相对该分支的全 11 档配对净差 **−0.519 pp**，源级 95% CI **[−0.968,−0.094]**。因此，虽融合显著优于两个**历史冻结**基线，当前证据没有证明融合优于本轮共享训练产生的最强单分支，也没有隔离“共享训练/输入分布改变”与“固定融合”的贡献。

α均值从 −10 dB 的 **0.3579** 随 SNR 降至 +10 dB 的 **0.0123**。但 −10 dB 共享 Raw/Projection logits 的平均 L2 范数为 **4.61/57.22**，Projection 明显更大；仅凭 `α<0.5` 不能断言 Raw 决定输出。+10 dB 两分支范数约 **34.19/33.13**。逐 SNR logits 范数、两个输出位置的真实类对最强错误类 margin、α分位数均已留存。

以 PairExact 计，−10 dB 共享 Raw 错/Projection 对 **533** 源、Raw 对/Projection 错 **24** 源；融合纠正 Raw **534**、破坏 Raw **24**，而相对 Projection 纠正 **39**、破坏 **38**。+10 dB 对应两分支互补 **95/73**，融合相对 Projection 纠正 **73**、破坏 **94**。详见 [`共享双分支与融合纠错.csv`](共享双分支与融合纠错.csv)。

Development −10 dB 盲支持错误 **51/3380** 源，α均值 **0.3929**（正确支持 **0.3574**）；错误支持组融合 PairExact **3.922%**，正确组 **16.642%**。这只说明条件关联；低 SNR 难度同时影响支持和分类，不能把全部差异归因于 SOMP 错误。

## 5. 裁决与论文表述边界

**PARTIAL。** 固定融合同时提高低 SNR 与全 11 档 PairExact、Macro-F1，保留并超过冻结 Raw 的高 SNR 总体 PairExact；QPSK→PSK8/PSK16 合并错误明显下降。但高 SNR PSK8 Recall 下降 **6 pp**，QAM256 下降 **4 pp**，且融合低于同网 Projection 单分支。按预注册条件，不能晋升为无明显类别代价的有效核心方法，也不能称为解决了全部 PSK 类混淆。

论文可以报告：在此数据合同、单 seed、当前 SHELL 训练协议下，固定双视图共享训练模型有明显 Development 配对收益，并记录 QPSK 混淆改善与类别退化。不能宣称固定 α 的独立因果收益、SOMP 或投影单独导致分类收益、跨 seed 稳定性、Final Test 泛化结论，亦不能将本研究包装为新反混叠恢复。Full80 低 SNR PairExact 仍高出融合 **20.676 pp**。

本轮训练、评价和归档到此停止；不据 Development 调整 α、checkpoint 或训练参数，不自动启动下一模型。

## 6. 资源、复现和文件

门禁时 batch512 原视图/1024 CNN 输入的 GPU1 峰值已测得 allocated **10.434 GiB**、reserved **10.816 GiB**；正式训练运行时 `nvidia-smi` 约 **12.1 GiB**，四卡服务器其余三卡空闲。训练结束后 GPU1 释放；可用 RAM 约 **115 GiB**、磁盘剩余约 **233 GB**。与单视图模型相比，每批共享 CNN 要处理双倍输入且进行 Blind 支持/投影，计算成本实增；现有日志没有隔离的同硬件逐步耗时对照，因此不报告虚构的精确倍数。鉴于融合并未优于同网 Projection 分支，**额外融合推理成本尚未证明物有所值**。

原始 200 epoch history、配置、最佳 checkpoint、Development 逐视图预测及三分支 logits 已保存在本地 `results/raw/` 与服务器该账号自有运行目录。逐视图身份及 13 类所有指标可由 [`analyze_gate3e.py`](../code/analyze_gate3e.py) 再计算。GitHub 归档报告、代码与文本 CSV；大型 checkpoint、逐视图原始文件和二进制 logits 保存在本地与服务器，不进入 Git 仓库。
