## 文件保留级别

|级别|内容|处理|
|---|---|---|
|A 原始不可替代|源隔离数据、manifest、source/noise UID、训练配置、代码快照、checkpoint、逐样本预测、训练日志|保留并核对哈希；不可自动删除|
|B 研究结论|中文报告、指标 CSV、混淆矩阵、图、QA 门禁|纳入版本归档；不能覆盖旧版本|
|C 可再生中间物|临时解压包、编译缓存、重复下载包、失败预检目录|先列清单并核对无进程引用，再按具体路径清理|
|D 大体积文件|train/validation/development H5、模型 checkpoint|保留在服务器及本地备份；GitHub 只存 manifest、哈希和位置索引，除非另有大文件存储方案|

## GitHub 归档结构

建议新建**私有**专用仓库，使用 `experiments/YYYYMMDD_实验名/` 每轮一目录：`README.md` 写研究问题和状态，`protocol/` 存冻结配置与运行命令，`code/` 存精确训练/评价脚本，`results/` 存报告、指标与必要预测，`manifests/` 存数据和 checkpoint 哈希。仓库根目录放总索引，标注每轮状态（计划、运行中、已复核、废弃）及与前一版关系。不得上传服务器密码、SSH 私钥、Final Test 数据、数十 GB H5 或未经必要性评估的大 checkpoint。
